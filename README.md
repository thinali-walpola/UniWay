# UniWay – University Event & Student Platform

## 📌 About the Project

**UniWay** is a web-based platform designed to help university students discover university events, explore opportunities, and stay connected with activities happening around them.

The main purpose of UniWay is to make it easier for students to find interesting events, view event information, and register for activities through a simple and user-friendly interface.

## ✨ Features

- **Home Page** – A clean and modern landing page.
- **Event Discovery** – Browse different university events and activities.
- **Event Details** – View event descriptions and additional information.
- **Event Registration** – Register for events using the registration interface.
- **Search Function** – Find events more easily.
- **Interactive Modals** – View event details and registration options in popup windows.
- **Responsive Design** – Designed to work on different screen sizes.
- **Navigation Menu** – Easily navigate through the website.

## 🛠️ Technologies Used

- **HTML5** – Used to create the website structure.
- **CSS3** – Used for styling, layouts, colors, and responsive design.
- **JavaScript** – Used to add interactive features and functionality.
- **Google Fonts** – Used to improve the website typography.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder using Visual Studio Code.
3. Locate the `index.html` file.
4. Open it using your browser.

You can also install the **Live Server** extension in VS Code and right-click `index.html`, then select **Open with Live Server**.

## 🎯 Project Objective

The objective of UniWay is to create a convenient digital platform where university students can discover events and participate in university activities.

The project focuses on providing a simple interface, easy navigation, and interactive features to improve the overall user experience.
